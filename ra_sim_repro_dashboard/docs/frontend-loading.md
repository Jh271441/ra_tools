# 仿真管理加载与轮询

## 加载约定

- 仿真管理的首屏不加载 Issue 表格、Issue 详情、服务状态和总览图表代码。
- 明确选择版本时，Flow 的 JS/CSS 与看板请求并行。当前业务版本页沿用不展示 Flow 的约定。
- 参数编辑器在接近可见区域、点击参数入口或 URL 带 `parameters=1` 时加载；轮询不重置已经编辑的参数。
- 桌面画布与手机阶段列表只挂载当前布局，断点沿用容器宽度 760px。已选阶段和键盘焦点在重排后保留；活动主路和旁路保留流动动画。

## 展示缓存和写操作

- 缓存只在当前浏览器页面的内存中存在，最多 8 个版本、120 秒，不写入 localStorage。
- 回切已访问版本可立即显示最近快照，仍重新请求 API。核对成功之前禁用提交、关联、模式切换和 Resume。
- 失败保留最后快照，提示数据过期并禁用写操作。旧请求晚返回不能替换新选择，手动强制刷新能取代在途轮询。
- 写操作清理所有展示缓存，后续读取绕过写入前的在途 GET。缓存从不作为提交或发布决策依据。
- 未变化的响应和小型图投影保持对象引用，避免仅因轮询重新生成所有节点与边。

## 轮询

- 隐藏页面不发轮询；恢复可见立即读取。同一轮读取结束后才安排下一轮。
- 常态间隔 30 秒；进度刷新中最多连续 3 次使用 5 秒间隔，然后恢复 30 秒。手动刷新只读取一次看板。
- 轮询只读看板缓存；Trail/Orion 同步仍由服务端既有 worker 周期控制。

## 回归入口

`frontend` 下执行 `npm run test:unit` 和 `npm run build`。

- `tests/liveView.mjs`：版本隔离、请求竞态、失败快照、写后失效、刷新优先级、缓存期限和隐藏页面轮询。
- Vite 的 `tests/board-preview.html?version=gen4-release-20261016`：700ms 本地模拟响应、失败切换和请求计数，所有写操作仅在页面内计数，不连接生产服务。
- `tests/flow-preview.html`：阶段、旁路、运行/失败/归档等状态。响应式验收覆盖 320、390、1440px，并检查中英文与深浅主题、键盘和溢出。

测量时分别记录接口耗时、资源加载结束和流程图可交互时间；浏览器控制工具的调用耗时不能作为页面耗时。

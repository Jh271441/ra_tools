Qwen 原生 · 冻结权重

Qwen3.8-27B 预训练多模态基座

  • 视觉分支：27 层 ViT（d=1152, 16 heads, patch=16, merge=2×2）经视觉投影映射至 5120 维。
  • 混合语言解码器：64 层（d=5120, 上下文 262K），3:1 交替包含 48 层 Gated DeltaNet 与 16 层 GQA 全注意力。
  • 原生 LM Head 直接输出首位置 248,320 词表 Logits；视觉编码器、FFN 与基座权重全程冻结。
AutoTriage · 唯一训练参数

checkpoint-330 LoRA 微调配方

  • 低秩适配器：r=16、α=64、dropout=0.1，仅挂载两类注意力的 9 个投影矩阵，跳过 FFN/MLP。
  • 数据与损失：0206v2 + 0522（1,162 训练 / 132 源验证），单类别 token 监督，类别权重 A:2.0 / B:2.2 / C:3.5。
  • 训练进度：BF16、AdamW、lr=1e-4、cosine + 5% warmup，全程 6 轮 / 438 步，线上采用第 330 步（Epoch 4.52）。

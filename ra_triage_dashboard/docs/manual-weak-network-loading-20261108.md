# Manual 浏览器弱网加载优化

基线 `b743bfb7` / cache773；候选前端 cache774。沿用现有 Manual 页面、共享组件和权限。仿真看板不在本次范围内。

## 缩短浏览器依赖链

页面此前在正文末尾请求 `app.js`，下载执行后才请求主脚本。入口现在从 head 预加载带相同版本的 `/static/app-bundle.js`，正文直接执行该 bundle；两处 URL 一致，浏览器复用已发出的下载，冷启动少一次 loader 请求。`app.js` 作为已有链接的兼容入口保留，业务模块和经典脚本顺序仍由 MANIFEST 管理。CSS 顺序、mobile.css 最后覆盖以及资源 gzip/ETag/缓存策略不变。

标注汇总此前每次都串行请求任务目录、统计数据。现在同时发出两项请求；未选择具体任务时，统计内容独立显示，任务目录返回后只更新共享任务选择器，保留表格、其他筛选、分页与焦点。目录未就绪时任务选择器禁用，其他已就绪筛选可用。目录失败不抹掉已成功加载的全部标注统计。

URL 指定具体任务时，统计请求与任务验证重叠，但必须等待目录确认任务有效才显示。无效任务会取消原请求，再按既有规则切回全部标注查询，不显示错误范围的中间结果。保留任务/数据集/URL/请求序号校验，不将其他页面或旧筛选的响应用于当前页面。没有新增跨会话数据缓存。

## 网络波动与过期请求

汇总和 Review 图库的新查询取消前一个查询；离开页面也取消所属查询，阻止旧传输和客户端重试继续占用网络。取消客户端响应不保证终止已经进入数据库的服务端计算。

共享 API 包装器原先在调用方传入 AbortSignal 时不设置超时，网络挂起可能无限等待。现在所有 GET 都保留每次 6 秒的网络期限，将调用方取消传递给每次请求，并在结束时移除监听器。保持最多 3 次可重试 GET 及原退避策略；主动取消不重试，POST/PATCH/DELETE 等写请求不自动重放。持续故障仍可能用尽重试预算，不能将有界失败等同于网络恢复。

## 浏览器验证

用实际完整页面、相同合成只读 API、gzip、20 Mbps 带宽和固定 300 ms 浏览器网络延迟进行对比，每个版本/场景使用三个全新 Chromium 上下文。指标是导航开始到汇总明细内容可用。

| 场景 | cache773 中位数 | cache774 中位数 |
| --- | ---: | ---: |
| 固定网络延迟，目录 1200 ms | 3089 ms | 1574 ms |
| 响应抖动，目录 1800 ms | 3697 ms | 1576 ms |
| 首次统计 GET 连接中断 | 3191 ms | 1706 ms |

抖动使用按端点固定的 40/100/400 ms 服务响应延迟和较慢目录；连接中断由测试服务在首次 GET 返回响应前关闭连接注入。不是实际 VPN 丢包率测试，也不是生产端到端或 p95。前后相同资源压缩，避免把压缩差异误计为此次改进。

复现（Playwright 使用既有本地运行时）：

```bash
STARTUP_ROUTES=summary STARTUP_MEASURE_ONLY=1 STARTUP_TRIALS=3 \
STARTUP_NETWORK_MS=300 STARTUP_NETWORK_PROFILE=jitter \
node ra_triage_dashboard/tests/startup_dependencies_browser.cjs
```

加 `STARTUP_TEST_REF=b743bfb7` 使用旧版页面资源；profile 支持 normal/jitter/transient。

实际 JS 检查覆盖有信号 GET 的超时、取消后不重试、无信号 GET 单飞、写失败不重放；汇总目录延迟/失败、有效与无效任务、路由规范化、过期响应隔离；图库实际取消旧传输。旧版可稳定复现新增超时回归失败。

本地 Chromium 响应式验收覆盖六个入口 × 320/390/1440px × 中英文 × 深浅主题，共 72 组：内容在目录被阻塞时显示、共享下拉禁用/恢复和 Escape、移动筛选展开、语言/选择保持、翻页及 URL、无页面横向溢出、预加载只下载一次主脚本。保留既有页面中未在本次修改的原始文案；这些检查不表示完整页面所有旧词条均已翻译。测试不代表真机、软键盘或 Safari/iOS。

发布结果与生产浏览器复核以统一部署 receipt 和当前交接记录为准。改动减少额外链路等待和过期传输，不改变代理、VPN、DNS、网关或认证策略，不能承诺所有实际网络波动消失。

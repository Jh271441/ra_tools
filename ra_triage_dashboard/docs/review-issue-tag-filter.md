# Review Issue 子标签筛选

## 契约

判错复核筛选区在“共享标签状态”旁增加“Issue 标签 / Issue tags”。复用共享
`renderMultiFilter` 分组多选、定位、关闭和键盘交互；搜索复用该组件的可选能力。
桌面 ≥1180px 使用语义类名分配两行，不能因新增控件变成第三行。
手机继续使用原有折叠筛选与响应式规则，不强制两行。

- 环境、自车意图、误触发、应该触发、正确触发、无需协助六组。
- 同组任一、跨组同时满足；未选不限制，包含无标签 Issue。
- 搜索时全选/反选只作用于可见匹配项，保留搜索外已选项；清除取消全部。
- 收起只显示已选数量，完整名称保留在 tooltip；组间关系放在控件提示中。
- 从当前 Issue 标签投影读取：有效完整裁决优先，否则使用当前有效来源版本。
  不读取未保存草稿，不累加所有历史，不按负责人改变共享标签语义。
- 当前空标签是权威结果；只有不存在 Issue 标签投影时才沿用分析的旧标注兼容路径。
- GT 原值和同名 Issue 标签是独立筛选。未知键返回400，不静默扩大范围；已选停用标签可清除。
- 不改变标注、GT、排除、裁决、任务归属、完成状态或模型结果；无迁移、无 Trail 调用。

## 查询一致性

URL 使用 `issue_tags` 原始键列表；路由恢复、重置、语言切换、翻页、详情返回沿用
同一状态。后端验证目录后生成私有分组条件，在400条候选批次投影并在分页前筛选。
私有条件不传入底层普通查询。列表、总数、完整导航ID、导出、负责人查询、分配快照
使用相同过滤路径。新任务入口清空上一次标签选择；任务来源链接恢复其快照选择。

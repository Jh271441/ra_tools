预览的`motion=1`记录布局及透明度，`--static-dir`可加载旧版静态文件进行对照；

## 真实模拟器补验与按钮修正

2026-10-21 用户指出窄屏标签按钮的新增、计数和展开按钮挤压。手机标签组继续复用已有 Review 多选面板；原来的新增按钮移动到展开面板底部，桌面恢复原位，保留监听器、权限和唯一节点。去掉小于400px时强制分成标题/动作两行的覆盖规则，计数使用可读字号；讨论/历史不再强制各占半行，排除选项保留完整换行说明。

Android SDK / Pixel 7 / Android 15 ARM64 的安装和许可已获用户授权。模拟器初次启动遇到 ADB 自动定位警告，启动脚本已显式设置 SDK 和 platform-tools 路径。已在真正运行的 Android 虚拟机中测试；操作通过定向 ADB 执行，后台无窗口，不连接实体手机、不移动 Mac 鼠标。

实际 Android 对照还发现保存按钮在表单未滚到底时悬浮遮挡讨论和期望输出。手机保存按钮改为表单末尾的正常文档流，保留48px主操作高度；软键盘和表单内容不再被悬浮按钮覆盖。

新增标签对话框也以 visualViewport 的位置和高度限制卡片，解决真实 Gboard 展开后名称可见、底部取消和添加被键盘遮住的问题；桌面不受这项手机规则影响。

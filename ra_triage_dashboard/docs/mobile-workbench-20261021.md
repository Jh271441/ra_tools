# 手机交互修复 · 2026-10-21

本轮沿用已有手机布局、双列 Case/汇总筛选、成对标签和首行数据集选择。只修改展示和交互，不调整标注、分配、计数或权限。

- 详情的媒体/标注快捷入口在滚动时保留，位置随真实顶部高度更新；跳转预留顶部和入口高度，避免标题被遮挡。
- 四组可折叠筛选底部增加“收起筛选，查看结果”。已有筛选仍即时生效；收起保留条件和页面 URL，关闭残留下拉并恢复焦点。Review 分类条件也使用两列，Run、Issue、任务和模式保留整行。
- 窄屏或触屏下，问题标注、联合复核和模型复核的 textarea 回车正常换行，不触发保存；桌面 Enter 保存、Shift+Enter 换行和中文输入法保护保持。
- 通用下拉与标签弹层使用 visualViewport 的尺寸和偏移；软键盘/缩放后重新定位，关闭/卸载的弹层释放跟踪。长选项换行，滚动留在弹层内；更多菜单在矮屏可滚动。
- 补齐 MANIFEST 中缺失的 mobile-workbench.js 和 case-label-explanation.js，并严格检查与 loader 顺序一致，保证实际页面与前端测试使用同一模块集合。

验收使用真实前端模块、合成数据及禁止写入的本地预览。浏览器响应式视口验证不等于真实 iOS/安卓软键盘实测；生产公开页面的浏览器连接此前超时，线上身份和提交操作未模拟。发布与测试结果另见 reports/manual_mobile_20261021/release.md。

### 汇总与上传逻辑审计（2026-10-29，缓存版本707）

保留706版主页面设计。核对上传页与现有标注汇总的共同人工投影，并使用真实本地SQLite覆盖未标注、有效分类、冲突、有效裁决及来源变化后的失效裁决。汇总的「已提交」可以包含冲突提交，因此不等于上传页的有效已完成数量。

修复以下问题：批次中途停止时，后续条目原先仍显示待上传；浏览器提交响应丢失时，原先没有恢复操作记录；失败原因与实际读回值原先未展示。新增逐条结果、原因、读回值与本次结果刷新；提交后清除旧选择和远端缓存。失败明细表在手机局部横向滚动，避免长说明逐字换行；修复通用按钮!important覆盖，使预览和确认主按钮实际达到48px。

覆盖权限只作用于冻结预览内的旧值，不允许覆盖预览后才出现的新值。提交前核对整个批次，每条写入前再次检查原始投影指纹、当前版本成员范围及Trail值。预检失败会持久化未执行记录；执行中范围或来源变化会停止后续条目。传输层额外限制实际payload只能包含固定RD字段和三种合法值，防止上游适配器变化扩大写入范围。

## 数据口径

数据集选择器沿用顶部共享控件。当前活跃标注 scope 与版本 target membership 共同限定范围。每个 Issue 使用 `project_issue_label_states` 的原始 baseline scope 投影；有效 Issue 裁决参与，来源变化会使裁决失效。

只有 `resolved` 且具有有效三分类结果才能上传。待标注、冲突、stale、仅排除意见均不能充当分类结果。不得由 GT、模型预测、TE 标注或联合任务确认状态推导 RD 分类。GT 与模型字段不被此功能更新。

页面提供 Issue 搜索、标注状态筛选、范围计数、人工结论、贡献者、远端当前值、上传状态；50 条/页。先显式核对本页 Trail，再选择本页可上传项。筛选、换页、换数据集或刷新会清除旧选择与远端缓存；上传不会隐式包括其他页。批次 API 最多 100 条。

远端值相同则跳过；空值可上传；不同的非空值需管理员明确开启覆盖并逐项预览。待标注或冲突记录即使开启覆盖仍不可上传。

## HTTP 契约

| Manual API | 用途 / 权限 |
|---|---|
| GET `/api/rd-results?baselines=…&q=…&status=…&page=…&page_size=…` | 只读本地汇总；writer/admin；每页10/20/50/100，默认20，页码越界收敛到有效页 |
| POST `/api/rd-results/status` | 只读核对所选 IDs 的 Trail 值；writer/admin |
| POST `/api/rd-results/preview` | 创建 10 分钟的冻结预览；admin |
| POST `/api/rd-results/preview-scope` | 按当前数据集、搜索和状态筛选创建跨全部页的冻结预览；admin |
| POST `/api/rd-results/commit` | 确认预览并上传；admin + 写入开关 |
| GET `/api/rd-results/operations` | 最近 30 次执行记录；admin |
| GET `/api/rd-results/operations/{id}` | 单次冻结明细与逐条结果；admin |

status/preview 请求为 `{baselines, issue_ids, overwrite: false}`。commit 为 `{operation_id, confirmed: true}`。不接受浏览器提供的分类值或作者；服务器从当前人工投影重新取值。预览和提交需要现有同源请求标记；生产验证身份沿用现有中间件。

preview-scope请求为`{baselines, q, status, overwrite: false}`，范围由服务器解析，不接收客户端枚举的分页ID。复用汇总的范围和筛选规则，跳过无有效标注，按每100条分批读取Trail；任一分片不完整则整个预览失败，不产生可提交记录。范围上限沿用数据集20000条限制；本页手动选择仍限100条。预览返回范围总数、无有效标注数，以及逐条已一致/不同/待上传状态；只有待上传或明确允许覆盖的条目可执行。预览本身无远端写入。

实际外部接口复用现有 `rd_review_sync.TrailHTTP` 与应用鉴权：
`POST https://voyager.intra.xiaojukeji.com/paladin/issue/pool/multi_update/`。
每次只发送 `issue_info[issue_id].ra_rd_review_result`，不复用会写入额外 info 标记的排除 writer。

| Manual 结论 | Trail 存储值 |
|---|---|
| 正确触发 | 成功 |
| 误触发 | 误触发 |
| 无需协助 | 无需协助 |

传输隔离于共享进程代理配置：单次 requests Session、trust_env=false、固定域名与路径、禁重定向、连接/读取超时、无自动重试；凭据仅由既有客户端生成请求头。

## 提交与恢复

`DASHBOARD_TRAIL_RD_WRITE_ENABLED` 默认 false；关闭时允许核对和预览，提交返回 403。部署及开启该开关未在本任务执行。

预览冻结 actor、范围、原始 revision/decision 身份、投影指纹及远端字段。提交先重新检查整个批次，再逐条重读本地/远端；变化即阻止写入。执行前保存 durable intent；请求返回后读回 RD 并核对四个保护字段：`ra_stuck_auto_result`、`ra_stuck_auto_result_info`、`ra_review_reason`、`ra_merge_result`。不以 HTTP 200 判断成功。响应丢失但读回一致时记录 verified，同时保留 acknowledged=false。

记录存放在持久化 data_dir/rd_publications，0600 文件、原子替换、文件和目录 fsync、跨进程文件锁。同一成功 operation 重放返回原记录；中断/失败的 operation 不盲目重发，需查看记录并重新核对生成预览。记录是该次执行的历史结果，不代表 Trail 永远保持该值。

逐条执行结果语义：

| 状态 | 含义 |
|---|---|
| `verified` | 写后读回RD一致，保护字段未变；即使写入响应丢失仍可核验成功 |
| `unverified` | 已发起写入，但读回失败、值不一致、保护字段变化或执行中断；不能断言未写入 |
| `not_attempted` | 尚未发起该条写入；包括预检失败、来源/范围变化及前序条目异常后的停止项 |
| `intent` | 持久化了写入意图，操作仍在执行；若无执行进程持有文件锁，转为中断未确认 |

返回客户端的读回值仅为RD值，不暴露保护字段快照。预览显示覆盖数量、旧值与新值；执行记录显示已核验、未确认、未执行的数量及逐条原因。

浏览器未收到commit响应时只GET原operation的记录，不重发POST。GET也失败时保留操作ID与已有结果，显示结果暂不可查，可刷新本次结果。GET暂时仍返回preview时，请求可能处于预检/排队中，不能视作确定未执行；界面保持结果未知且不再开放本次提交按钮。恢复原记录不会重新读取Trail或重发写入；未确认条目须关闭弹窗后重新核对Trail并创建新预览，当前值已一致的条目会跳过。

Trail 无 CAS，仍存在最终检查与远端写入之间的外部并发窗口。文件锁只覆盖共享此 data_dir 的本功能进程。提交可能部分完成；未核验项停止后续写入。未对外部系统、GT、标注或任务提供回滚操作。

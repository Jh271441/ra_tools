# Manual 版本指标

入口为「每日数据 → 版本指标」(`/version-metrics`)，版本数据页也提供同版本快捷入口。
页面复用 Manual 的主题和共享选择控件，上方一张趋势图，下方版本报告表与默认收起的阈值分析。

- 五种方案按钮常驻，使用短名，完整口径在提示中说明；新链接默认选择「模型＋规则」和「规则后人工」两条线，已有链接的显式选择保持有效。桌面按钮视觉高度 30px，手机触控区域至少 44px。
- 图内不再重复指标标题、版本数和抽样说明；只保留方案选择、Trail 采集时间、`conf < 0.90` 和共享信息提示。时间徽标保守显示所选版本中最早的采集完成时间，完整采集窗口及最新时间在提示中列出。参考、排除规则、人工模拟含义收进信息提示；加载和刷新异常才显示状态文案。
- 数值相同的点合并一个标签，悬停仍逐方案列出精确结果和分母；不同的相近值按像素距离向上避让。点位保持真实值。
- 折线画法对齐 sim 的 `PrComparison.tsx` / `releaseChart.ts`：仅按可见曲线自适应纵轴，0–100% 内分四等区间、五条整数百分比刻度；288px 图高、虚线网格、2.5px 实线和空心点。横轴各版本等宽居中，日期 `MM-DD`，超过 12 个版本时减少日期刻度。缺失值断线。
- 浮层以同一版本中心竖线定位，距右侧 40px，空间不足时向左；两侧都放不下时移至图表上方。图中数值一位小数，浮层和报告表保留两位。

版本报告表始终完整展示五种口径，不受曲线开关影响；跟随上方指标、参考、排除和 conf 条件更新。每版本一行，包含有效/抽样量、TE/RD 已标量及比例、五方案得分和各自分母。ACC 显示正确数/覆盖数；分类召回显示 TP/support；Macro-F1 显示覆盖 n。
1009、1016、1023、1030 行的版本日期下提供对应 Cooper 报告链接，新标签页打开；报告只作原文参考，页面指标仍来自 Trail 快照。未知版本不生成猜测链接。
分页复用 `.case-pagination`、`.case-pagination-main`、`.case-page-size`、`.page-jump-control` 和 `CASE_PAGE_SIZES`，默认 20 行。完整趋势摘要已由一次有界请求返回（最多 50 个版本），本地分页共用同一批摘要；初始请求仍将分页参数交给后端校验。

折叠阈值表默认选择当前范围最新版本，使用共享增强下拉。完整展示每档 conf 的已回刷全量低置信数量/比例、相较 0.90 的减少数、有效抽样中的人工量、抽样模拟 ACC；当前 conf 行高亮。图和两张表始终使用同一份已保存回执，不复制报告数字。

## 口径

- 分母来自版本注册表中已经发布的概率抽样项，不使用顶栏 GT baseline，也不把低置信扩展集当随机样本。
- TE、RD、TE′、裁决分别读取 `ra_review_result_new`、`ra_rd_review_result`、`ra_review_result_sampling`、`ra_review_result_arbitrated`，不互相补位。
- 成功、失败映射为正确触发；OOS / out_of_scope、未接起、缺失和未知标签不进入三分类。人工排除默认不启用。
- 纯模型仅统计确有模型前向输出的项；模型＋规则包含实际发布的前置规则结果。两者覆盖数可能不同，tooltip 展示各自分母。
- 人工方案以当前参考替代低 conf 输出，始终标注「模拟」，不是独立人工复核准确率。前置规则优先、规则项不进入模型前向，因此两个链路人工模拟变体在当前流程下可能相同。
- 指标包括 ACC、固定三类 Macro-F1、各类召回率和抽样集人工介入比例。全量低置信工作量保留在服务端回执，分母是已发布全量，不能与抽样集 ACC 分母混用。

## 读取与刷新

`GET /api/version-metrics` 只读已有的完整 Trail 快照，不访问 Trail。
快照必须带有服务端采集来源、请求/返回数量、内容 SHA 与带时区的有效采集窗口；数量与实际行数一致，且窗口按时间顺序有效。
旧报告/预览回执可留存审计，但不能作为当前指标或明细的回退来源；尚未采集的版本明确显示「暂无 Trail 快照」。
用户点击「更新指标」后，经现有 writer/admin 身份校验及同源请求标记，启动一个后台只读采集任务。
它顺序处理选择的版本，Trail 查询每批 20 项、起始间隔至少 1 秒；不允许调用写接口。
须完整返回请求 Issue，并核对实际发布字段、固定 Run、规则来源、版本成员和排除状态。
不完整或读取中变化的回执不能替换该版本上次完整快照；允许其他已成功版本保留本次结果。
页面切走后停止轮询；返回时仍读取快照，只有显式操作启动远端采集。

快照位于 `DASHBOARD_DATA_DIR/version_metric_snapshots/<family>/`，内容 SHA 标识、校验后读取，历史保留。
没有客户端快照导入接口；该功能不写 Trail、模型 Run、GT 或人工标注。
后台使用跨进程文件锁防止重叠采集，异常返回固定错误码，不暴露 SDK 原始异常或凭据。快照不宣称持续实时；只有完整只读采集成功后才更新显示时间与指标。

URL 保存 `families`、`metric`、`schemes`、`reference`、`exclusion`、`threshold`、`page`、`page_size`、`threshold_family` 和 `threshold_open`。
更换指标/方案仅重画图表，读取中的同范围回执仍有效；更换数据范围或离开页面后旧响应失效。
默认显示最新六个已注册版本、TE 参考、0.90 模拟阈值和模型＋规则、规则后人工两条线。切换指标、数据范围或每页数量回第一页；切换语言保留当前页、方案、阈值分析版本和展开状态。

# 任务分配分享链接

任务分配页顶部、任务卡片和任务明细提供“复制链接 / Copy link”。链接打开任务分配页，
接收人可先看进度、负责人和 Issue 明细，再进入联合复核或原因聚类。

- 卡片复制整项任务的链接：指定 `split`，使用全部任务范围，移除发送人的“我的任务”和明细筛选。
  持续追加版本任务、固定任务、历史任务以及问题标注页的联合任务卡片共用该入口。
- 顶部和明细复制当前视图：保留任务范围、`assigned_to_me`，以及明细的负责人、状态、搜索、页码和每页数量。
  “我的任务”仍指接收人当前账号；需要固定某位负责人时在明细选择该负责人后复制。
- 明细筛选/翻页同步地址栏；刷新或重新打开分享链接恢复同一视图。加载明细时禁用明细复制入口。
  链接不包含其他工作区筛选、草稿或身份凭据。
- 现代 Clipboard API 成功后提示已复制；不支持或权限被拒绝时提供真实链接供手动复制，不显示成功提示。
- 沿用现有 writer/admin 权限。分享链接不授予权限，不修改任务分配、GT、RD 标注或提交进度。

验证：五项行为测试覆盖链接往返、跨任务筛选隔离、安全默认值、刷新 API 参数、剪贴板拒绝反馈；
本机实际 shell/modules 的合成 Chromium 页面覆盖 320/390/1440px、中文/英文、深/浅主题 12 组合，
另检查键盘激活、运行时语言切换、复制后新页面恢复、镜像卡片、明细和列表无横向溢出及手机44px触控目标。
这些是桌面浏览器视口验证，不是真机或已登录生产验收。发布由统一发布器执行完整测试与隔离灰度。

# 8786 移动端优化 · 2026-10-08

目标：覆盖常用工作流的真实手机交互，保持已有数据、权限、桌面功能和标注语义。

## 已发现的问题

- Case图库、标注汇总复用了手机折叠CSS，却缺少展开按钮，筛选不可达。
- 标题与快捷键重叠，顶部GT/操作占多行；图表和表单的字体仍过小。
- 汇总统计各占一整行，矩阵依赖横滑，标签图表挤占明细入口。
- 详情序号输入与相邻按钮重叠，媒体控件占多行，跳转到标注区不便。
- 分配名称为来源文字预留过多宽度，人员/配额/删除过挤，种子和底部动作错排。

## 本轮实现

1. 新增mobile-workbench.js集中手机展示交互。更多菜单移动原控件节点，保留ID、事件、权限；切回桌面恢复原位置。
2. Case/汇总补齐筛选展开入口，新增可达性回归防止隐藏表单没有按钮；保留原筛选参数及提交方式。
3. 顶部压缩，正文恢复可读字号及44px操作控件。侧栏打开时锁定背景滚动，Escape/遮罩关闭保持。
4. 汇总三列统计、手机可读矩阵、直达明细、按需展开场景图表；明细来源左对齐，正文/标签可读。
5. 详情媒体/标注区域跳转，修正分页输入尺寸，媒体控件并排，表单与保存控件便于触控。
6. 分配人员按完整姓名行+配额/删除行布局，来源标记下移，种子全宽，底部取消/创建并排。
7. 弹窗内部滚动、关闭按钮触控尺寸、安全区与提示；表格横滚限制在表格容器。

## 验收范围

- 320/390/430px手机、768px平板、1920px桌面；检查可见控件、局部滚动和页面溢出。
- Case/Review图库与详情、标注汇总、Case/Review分配草稿、侧栏与更多菜单；其它工具页进行布局检查。
- 操作仅限筛选、展开、导航、草稿人员增删；不生成真实任务、不保存标签、不执行GT/Trail/模型写入。
- 精确版本云端完整测试与冻结数据/API对照；部署仅8786，保留前版本回滚。

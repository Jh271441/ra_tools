# 问题标注详情导航

详情页的总数、序号跳转、上一条/下一条与全部筛选结果一致，不受图库每页条数限制。
图库仍分页加载完整卡片，进入详情和跨页导航不改变图库的页码；返回筛选结果时
保留原来的页码、页大小和筛选条件。

`GET /api/labeling/cases` 在分页 `items` 之外返回 `queue_issue_ids`。两者来自同一次
`_project_labeling_cases` 的结果，权限、数据集激活、任务、作者、分配人、状态、
排除、GT、标签、搜索、Issue ID 和聚类条件以及顺序完全一致。队列只包含 ID，
不加载全量详情或媒体，不增加一次全量数据库投影。

详情按此 ID 队列展示位置、切换和跳转；不在筛选结果中的显式详情链接可继续显示，
但位置和相邻导航禁用，不能误跳到第一条。队列随着图库加载结果更新，不修改
筛选条件来强行保留已经不匹配的 Issue。旧服务未返回该字段时保留原分页导航兜底。

回归：`test_case_labeling.py` 覆盖已排除的45条筛选结果、10/20条分页、ID子集与空结果。
`case_labeling_queue.cjs` 使用实际详情加载/导航代码和合成只读媒体/API，验证20→21、
21→20、全量序号跳转、首尾禁用、无效序号、范围外详情、返回原图库及1440/390/320px
中英深浅主题。浏览器缩放测试不代表真机或线上SSO验收。
